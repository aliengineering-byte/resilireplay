## Status vocabulary

During development this ledger uses `Open`, `In progress`, `Closed`, and `Deferred`. The draft release audit will additionally assign each gap exactly one terminal disposition: `FIXED`, `PROFILED_PROVISIONALLY`, `DEFERRED_NORMATIVE_DEPENDENCY`, `EXTERNAL_INDEPENDENCE_REQUIRED`, `OUT_OF_SCOPE_SECURITY`, or `REJECTED_WITH_REASON`.
