## Status distinctions

- “Normative MCP” above refers only to the released official MCP specification.
- “Released implementation behavior” describes an official tool/SDK at the pinned revision and is not automatically protocol law.
- “Proposed” means open and unmerged.
- MCP-RES requirements are project design decisions unless explicitly incorporating an external normative reference.
- Any conclusion about suitability for reliability evidence is an MCP-RES inference, not a statement by the cited project.
