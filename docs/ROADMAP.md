# Roadmap

Realistic post-v0.1 work:

- OpenTelemetry trace import/export adapter.
- First-party adapters for additional agent frameworks while preserving the same core schema.
- Streamable HTTP server fixture and proxy integration tests on all CI platforms.
- Incremental streaming-event schema in a backward-compatible trace version.
- Richer causal minimization for concurrent branches.
- Signed local attestations for report bundles.
- Optional, clearly non-authoritative natural-language explanations that never affect scoring.

Hosted scanning, universal certification, autonomous Internet discovery, and destructive host fault injection are intentionally out of scope.
