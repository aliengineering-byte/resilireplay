# MCP Inspector `mcp.json` compatibility matrix

Reviewed upstream: MCP Inspector `2.0.0`, commit
`7aebf168e6277ea26b1f04a7987a1cd11328ec83`. The Inspector source of truth was its released
[`mcp-server-configuration.md`](https://github.com/modelcontextprotocol/inspector/blob/2.0.0/docs/mcp-server-configuration.md)
and released config/runtime types. Protocol transport behavior was reviewed against MCP revision
[`2026-07-28`](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports).

| Inspector field/form                                                                | ResiliReplay interpretation                      | Status                           | Security rule                                                                        | Validation error                                               |
| ----------------------------------------------------------------------------------- | ------------------------------------------------ | -------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| Complete `{ "mcpServers": { ... } }` file                                           | Read-only named server map                       | Supported                        | File and resolved symlink stay inside CLI repository root                            | `RR_MCP_CONFIG_MISSING_SERVERS`, `RR_MCP_CONFIG_PATH_ESCAPE`   |
| Standalone server-entry object                                                      | One map value without wrapper                    | Unsupported                      | Avoids guessing a server name or file shape                                          | `RR_MCP_CONFIG_MISSING_SERVERS`                                |
| One named entry                                                                     | Auto-selected                                    | Supported                        | No ambiguity                                                                         | —                                                              |
| Multiple named entries                                                              | Selected only with `--server`                    | Supported                        | Prevents auditing the wrong target                                                   | `RR_MCP_CONFIG_SELECTION_REQUIRED`                             |
| Missing or unknown selected name                                                    | No target                                        | Rejected                         | Never falls back to another entry                                                    | `RR_MCP_CONFIG_UNKNOWN_SERVER`                                 |
| Missing `type`                                                                      | Stdio, as in Inspector                           | Supported                        | Requires `command`                                                                   | `RR_MCP_CONFIG_COMMAND`                                        |
| `type: "stdio"`                                                                     | Direct child process                             | Supported                        | No shell; reviewed executable and array arguments only                               | `RR_MCP_CONFIG_COMMAND`                                        |
| `command`                                                                           | Executable name or contained path                | Supported                        | Control characters rejected; path links containment-checked                          | `RR_MCP_CONFIG_COMMAND`, `RR_MCP_CONFIG_PATH_ESCAPE`           |
| `args`                                                                              | Exact string array                               | Supported                        | Boundaries preserved; NUL rejected; path-like scripts resolved from config directory | `RR_MCP_CONFIG_ARGS`, `RR_MCP_CONFIG_PATH_ESCAPE`              |
| `env`                                                                               | String map passed only to child                  | Supported                        | Values never logged/persisted; Inspector auth-disable/session-token keys rejected    | `RR_MCP_CONFIG_ENV`, `RR_MCP_CONFIG_FORBIDDEN_AUTH_SETTING`    |
| Exact `${env:NAME}` value                                                           | One environment-variable reference               | Supported ResiliReplay extension | No general shell expansion; missing names fail                                       | `RR_MCP_CONFIG_ENV_REFERENCE`                                  |
| `$NAME`, `%NAME%`, `$()`, backticks, shell syntax                                   | Literal string                                   | Supported as literal             | Never evaluated by importer                                                          | —                                                              |
| `cwd`                                                                               | Working directory relative to config file        | Supported                        | Must remain contained, including through symlinks                                    | `RR_MCP_CONFIG_CWD`, `RR_MCP_CONFIG_PATH_ESCAPE`               |
| `type: "http"`                                                                      | Streamable HTTP alias documented by Inspector v2 | Supported                        | HTTP(S) URL only                                                                     | `RR_MCP_CONFIG_URL`                                            |
| `type: "streamable-http"`                                                           | Normalized Streamable HTTP stored form           | Supported                        | HTTP(S) URL only                                                                     | `RR_MCP_CONFIG_URL`                                            |
| `type: "sse"`                                                                       | Legacy HTTP+SSE transport                        | Supported, deprecated            | Same URL, header, and remote rules; prefer Streamable HTTP                           | `RR_MCP_CONFIG_URL`                                            |
| `url`                                                                               | Exact HTTP(S) endpoint                           | Supported                        | Userinfo, fragments, and credential-shaped query values rejected                     | `RR_MCP_CONFIG_URL`, `RR_MCP_CONFIG_URL_CREDENTIAL`            |
| Non-loopback URL                                                                    | Authorized remote target                         | Supported with `--allow-remote`  | Explicit ownership/authorization declaration required                                | exit `11`                                                      |
| `headers`                                                                           | String map sent on HTTP/SSE requests             | Supported                        | Values never persisted; CR/LF and controlled headers rejected; auth values redacted  | `RR_MCP_CONFIG_HEADERS`                                        |
| `connectionTimeout`                                                                 | Connection deadline in milliseconds              | Supported                        | Positive safe integer                                                                | `RR_MCP_CONFIG_TIMEOUT`                                        |
| `requestTimeout`                                                                    | List/call deadline in milliseconds               | Supported                        | Positive safe integer                                                                | `RR_MCP_CONFIG_TIMEOUT`                                        |
| `note`                                                                              | Non-executable Inspector export annotation       | Accepted and ignored             | Must be a string; never copied into evidence                                         | `RR_MCP_CONFIG_NOTE`                                           |
| `protocolEra: "legacy"`                                                             | Current SDK negotiation                          | Supported                        | Explicit value matches default                                                       | —                                                              |
| `protocolEra: "auto"` / `"modern"`                                                  | Inspector v2 protocol-era selection              | Unsupported in 0.2.0             | Never silently downgrade a requested wire era                                        | `RR_MCP_CONFIG_PROTOCOL_ERA`                                   |
| `oauth`                                                                             | Inspector-managed OAuth settings                 | Unsupported                      | Prevents partial or weakened authentication behavior                                 | `RR_MCP_CONFIG_UNSUPPORTED_FIELD`                              |
| `roots`, `metadata`, modern logging, tasks, pagination, extensions, fetch retention | Inspector-specific runtime behavior              | Unsupported                      | Execution-affecting fields are never silently discarded                              | `RR_MCP_CONFIG_UNSUPPORTED_FIELD`                              |
| `requestInit`, `eventSourceInit`, nested legacy `settings`                          | Arbitrary/obsolete runtime objects               | Unsupported                      | Avoids smuggling headers, callbacks, or ambiguous settings                           | `RR_MCP_CONFIG_UNSUPPORTED_FIELD`                              |
| Unknown transport                                                                   | No fallback                                      | Rejected                         | Never interprets an unknown type as stdio                                            | `RR_MCP_CONFIG_TRANSPORT`                                      |
| Unknown entry/top-level field                                                       | No fallback                                      | Rejected                         | Catches typos and schema drift                                                       | `RR_MCP_CONFIG_UNKNOWN_FIELD`, `RR_MCP_CONFIG_TOP_LEVEL_FIELD` |
| Duplicate JSON keys                                                                 | Ambiguous document                               | Rejected before import           | Prevents parser-differential configuration attacks                                   | `RR_MCP_CONFIG_DUPLICATE_KEY`                                  |
| Both stdio and URL fields                                                           | Conflicting transport declaration                | Rejected                         | No precedence guessing                                                               | `RR_MCP_CONFIG_CONFLICT`                                       |

Inspector v2 distinguishes its writable `--catalog` from read-only `--config`. ResiliReplay treats
either file's bytes as a read-only import and never creates, seeds, migrates, or modifies it.
