# ResiliReplay Everywhere

A no-key, CPU-only static demonstration of one synthetic tool failure becoming bounded evidence and an executable regression contract. It executes no command, accepts no uploaded trace, calls no model, and exposes no arbitrary MCP target.

The fixture is synthetic reliability evidence, not a vulnerability, benchmark, endorsement, or security certification. Source: https://github.com/aliengineering-byte/resilireplay
